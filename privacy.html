隱私權政策（Privacy Policy）

最後更新：2026-11-13

1. 這是什麼應用程式、誰在使用

PPMO-Ops 唯讀健檢是 YouTube 頻道「PPMO 阿瑋 裸K SMC 交易室」（https://www.youtube.com/@ppmo-awei）的經營者為自己的頻道開發的內部工具，由經營者本人在自己的電腦上執行。本應用程式不對外提供給其他使用者，目前唯一的使用者與資料主體就是頻道經營者本人。開發與營運者為個人，並非公司或機構。

本應用程式使用 YouTube API 服務（YouTube Data API 與 YouTube Analytics API）。使用本應用程式即表示同意受 YouTube 服務條款約束；Google 如何處理你的資料，請見 Google 隱私權政策。

2. 存取哪些 Google 使用者資料

經營者授權後，本應用程式僅使用以下兩個唯讀範圍：

範圍讀取的資料
youtube.readonly頻道名稱、頻道 ID、訂閱數、總觀看數、影片數；近期上傳影片的標題、發布時間、長度、直播狀態、隱私狀態、地區限制狀態、上傳處理狀態與各影片觀看數。
yt-analytics.readonly頻道層級的彙總分析數據：觀看次數、觀看時間、訂閱增減，以及依日期、內容類型、流量來源彙總的數值。

本應用程式不會讀取留言內容、收益資料、觀眾個人資料，也不會上傳、修改或刪除任何 YouTube 內容。

3. 如何使用這些資料

資料僅用於：檢查頻道狀態（例如影片遭封鎖地區、上傳被拒、隱私狀態變動、授權是否仍然有效），產生每日與每週報告，並在發現異常時提醒經營者。健檢目前由經營者在自己的電腦上手動執行，尚未設定自動排程；日後若改為排程自動執行，會先更新本頁面。預設只顯示 YouTube 提供的原生數值，不自行計算衍生指標。資料不會用於廣告，也不會用於建立使用者個人檔案，除上述目的外不作其他用途。

4. 如何儲存與保護

  • 授權憑證（OAuth 用戶端 ID、用戶端密鑰與更新權杖）儲存在經營者電腦的 Windows 憑證管理員，由 Windows 以使用者帳戶加密保護；不寫入程式碼、設定檔或日誌。
  • 讀取到的資料與報告以 JSON 與 Markdown 檔案儲存在經營者自己的電腦上。本應用程式沒有自己的伺服器、資料庫或雲端儲存空間。
  • 本應用程式只連線到 Google 的 API 服務（googleapis.com 相關網域）；執行記錄只記錄步驟與 HTTP 狀態碼，不記錄憑證或資料內容。

5. 是否分享、出售或轉移

本應用程式本身不會把 Google 使用者資料傳送給任何第三方服務，不會出售、出租，也不會將其用於廣告。

需要說明的一點：經營者目前會自行把報告的內容提供給自己使用的 AI 助理（Anthropic 提供的 Claude）閱讀與整理。這是經營者在本應用程式之外的自主操作；報告內容在該服務中如何被處理，取決於該服務的條款與經營者在該服務中的設定，不在本應用程式的控制範圍內，本政策無法對該服務的資料處理方式作出保證。經營者可隨時選擇不把報告提供給任何 AI 服務。

本應用程式對 Google 使用者資料的使用，以 Google API 服務使用者資料政策（包括其中的「有限使用」規定）為準。

6. 保留期限

  • 授權憑證：保存到經營者撤銷授權或自行刪除為止。
  • 影片 ID、標題、發布時間、長度、直播類型、隱私狀態、地區限制狀態、上傳處理狀態等非統計資料（包含每日快照與異常提醒中的相關內容）：保存不超過 30 個日曆日。本應用程式在每次執行健檢時，會自動清除已滿 30 日曆日的這些欄位（程式已具備此功能；目前健檢為手動執行、尚未設定自動排程，且至今尚無資料達到 30 日曆日而需要清除）。經營者會確保滿 30 日曆日的這些欄位被清除，必要時手動執行清除工具。
  • 統計數字（頻道訂閱數、總觀看數、影片數、各影片的觀看數，以及 YouTube Analytics 的觀看次數、觀看時間、訂閱增減等彙總數值，和依其整理的每日、每週報告）：在授權有效期間保存；每次執行健檢時會確認授權仍然有效，授權失效時依第 8 節處理。影片 ID 清除後，保留的各影片觀看數不再對應到特定影片。
  • 執行記錄只含步驟與 HTTP 狀態碼，不含 Google 使用者資料。

7. 如何刪除資料／提出刪除要求

  • 經營者隨時可以刪除本機的報告資料夾（每日、週報、通知、基準資料與執行日誌），即可刪除本應用程式保存的所有資料（本應用程式也提供需手動確認的清除工具）；在 Windows 憑證管理員中刪除名稱以 PPMO/ 開頭的項目，即可刪除本機儲存的授權憑證。
  • 如要提出刪除要求，請寄信至第 10 節的聯絡信箱；要求經確認後，會在 7 個日曆日內刪除已儲存的相關資料。
  • 刪除本應用程式保存的資料，不會影響 YouTube 自己儲存的資料。

8. 如何撤銷授權

經營者可隨時前往 Google 的安全性設定：第三方存取權（也可從 Google 帳戶的第三方應用程式與服務進入），找到「PPMO-Ops 唯讀健檢」並選擇移除存取權。撤銷後，本應用程式無法再向 Google 取得任何資料，之後的健檢會因無法取得授權而失敗，並提示需要重新授權。撤銷後，與該授權相關、已取得或已儲存的 Google API 資料，會盡快刪除，並在 30 個日曆日內完成。

9. 兒童

本應用程式不面向兒童，也不蒐集兒童的資料。

10. 政策變更與聯絡

如本應用程式存取或使用資料的方式有變動，會先更新本頁面。對隱私的疑問或申訴，請聯絡：aweippmo@gmail.com。

English summary

PPMO-Ops Read-only Health Check is a personal tool for the owner of the YouTube channel “PPMO 阿瑋 裸K SMC 交易室”. It uses YouTube API Services; by using it you agree to be bound by the YouTube Terms of Service, and the Google Privacy Policy applies. It uses only youtube.readonly and yt-analytics.readonly to read channel info, video metadata and aggregated analytics, and saves health-check reports as local files on the owner's computer (the check is currently run manually by the owner; no automatic schedule is enabled yet). OAuth credentials are kept in Windows Credential Manager. The app itself has no server or cloud storage and sends no data to third parties; it does not sell data or use it for advertising. Separately from the app, the owner currently pastes report contents into an AI assistant (Claude by Anthropic); how that service handles the content is governed by its own terms and the owner's settings there, which this policy cannot guarantee.

Retention: video IDs, titles, privacy status, region-restriction and upload status (non-statistical data) are kept no longer than 30 calendar days. Clearing is performed automatically each time the health check runs, and the owner ensures that fields reaching 30 days are cleared (manually if needed); the check is currently run manually, no automatic schedule is enabled yet, and no data has yet reached 30 days. Channel statistics and analytics are kept while authorization remains valid, and authorization is re-verified each time the check runs. Deletion: the owner can delete local data and credentials at any time; deletion requests sent to the contact address are fulfilled within 7 calendar days; deleting data held by this app does not affect data stored by YouTube. Revocation: access can be removed at Google security settings; related API data is deleted as soon as possible and within 30 calendar days of revocation. Use of Google user data is subject to the Google API Services User Data Policy, including its Limited Use requirements. Privacy questions or complaints: aweippmo@gmail.com.
